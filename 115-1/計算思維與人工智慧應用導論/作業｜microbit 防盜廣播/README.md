# micro:bit 防盜廣播

雙向 micro:bit 防盜警報器，符合以下作業要求：

- 使用 micro:bit 內建**加速度感測器**
- 使用**鱷魚夾 + 外接實體按鈕**觸發硬體功能
- 使用 **Radio 廣播**讓兩台 micro:bit 雙向溝通

## 兩台 micro:bit 的角色

兩台板子都使用同一份程式。

- 開機後顯示 `?`
- 按 micro:bit 本體 **A 鍵**：設定成防盜端 A
- 按 micro:bit 本體 **B 鍵**：設定成控制端 B

## 互動流程

1. 搖動 micro:bit A。
2. A 的加速度感測器偵測到 Shake。
3. A 顯示警報圖示，並透過 Radio 傳送 `ALERT`。
4. micro:bit B 收到 `ALERT` 後顯示警告。
5. 按下連接在 B 上的**黃色外接實體按鈕**。
6. B 偵測到 P0 被按鈕接到 GND，透過 Radio 傳送 `STOP`。
7. A 收到 `STOP`，停止警報並顯示勾勾。
8. A 再透過 Radio 回傳 `OK`。
9. B 收到 `OK` 後也顯示勾勾。

Radio group 固定為 **23**，兩台板子會使用相同頻道。

## 外接實體按鈕與鱷魚夾接法

控制端 B 使用兩條鱷魚夾，把**機械按鈕**接在 P0 與 GND 之間：

```text
micro:bit B

P0  ─── 鱷魚夾 ─── [ 外接按鈕 ] ─── 鱷魚夾 ─── GND
```

若按鈕模組有標示 **COM / NO / NC**，請使用 **COM + NO (Normally Open)** 這一組接點。

- **沒按按鈕**：P0 與 GND 不導通
- **按下按鈕**：P0 與 GND 導通
- 程式使用 P0 的內部 Pull-up，因此放開時讀值為 1、按下時讀值為 0

> 不需要接 3V。

## 在另一台電腦使用

1. 打開本資料夾的 `main.ts`，按 **Copy raw file** 複製整段程式。
2. 前往 `https://makecode.microbit.org/`，建立 **New Project / 新專案**。
3. 上方切換到 **JavaScript**。
4. 刪掉預設內容，貼上 `main.ts`。
5. 確認 **Extensions / 擴充功能** 裡有 `radio`（新專案預設就有）。
6. 開啟專案後，以 USB 連接第一台 micro:bit。
7. 按 **Download / 下載**。
8. 若瀏覽器支援 WebUSB，可以 Pair / Connect 後直接下載；否則把下載好的 `.hex` 檔拖到 `MICROBIT` 磁碟。
9. 第一台開機後按 micro:bit 本體的 **A 鍵**，設定成防盜端。
10. 第二台也下載**完全相同**的程式，開機後按 micro:bit 本體的 **B 鍵**，設定成控制端。
11. 在 B 上用兩條鱷魚夾將外接按鈕接到 **P0 與 GND**。
12. 搖 A，確認 B 收到警報。
13. 按下黃色外接按鈕，確認 A、B 最後都顯示勾勾。

## 作業影片建議流程

1. 同時拍到兩台 micro:bit 與黃色外接按鈕。
2. 第一台按 A、第二台按 B。
3. 搖動 A，展示加速度感測器觸發。
4. 拍到 B 收到 Radio 警報。
5. 按下透過鱷魚夾連接的黃色外接按鈕。
6. 拍到 A 收到 `STOP` 並顯示勾勾。
7. 拍到 B 收到 A 回傳的 `OK` 並顯示勾勾。

## 作業文字說明範例

本組設計「雙向防盜警報器」。第一個 micro:bit 作為防盜端，利用內建加速度感測器偵測物品是否被移動；當偵測到搖晃時，會顯示警告圖示並透過 Radio 傳送 ALERT 給第二個 micro:bit。第二個 micro:bit 作為控制端，收到警報後顯示警告。控制端使用鱷魚夾將外接實體按鈕連接在 P0 與 GND 之間，按下按鈕後會觸發硬體輸入，並透過 Radio 傳送 STOP 給第一台。第一台收到 STOP 後停止警報並回傳 OK，第二台收到 OK 後也顯示完成圖示，以此完成兩個 micro:bit 的雙向溝通。
