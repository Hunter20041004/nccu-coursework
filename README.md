# FactoryMind

工廠突發事件處理互動網頁，使用單一 index.html，CSS 與 JavaScript 寫在檔案內。

## 功能

- 觸發停機與急單，進行共同評估及候選方案比較。
- 調整企業政策門檻，先預覽確認，再重新評估。
- 查看工單前後差異、維修回報與復機確認。
- 完成必要工作後結案，查看及下載文字報告。
- 桌機與手機操作、模擬 AI 問答。

## 操作方式

開啟網站，點選「觸發停機與急單」，依畫面提示完成評估、擴大搜尋、套用、維修與結案。若先確認復機，需重新評估才能套用。

## 範圍

資料為合成情境，方案數字為預設示範值。AI 問答為腳本，沒有連接真實工廠、模型或排程引擎。角色僅示範責任，不是帳號權限。進度在重新整理後重設，報告請下載保存；評論只存於自己的瀏覽器。字體與 Tailwind 引用外部 CDN。
