# NCCU Coursework

**Programming assignments from my courses at National Chengchi University, one folder per course. Notebooks open and run in Google Colab with one click.**

政大修課的程式作業，一門課一個資料夾；筆記本點一下就能在 Colab 執行。

> **Type** Course projects · **Status** In progress (updated each semester) · **Role** Solo project · **Stack** Python, Jupyter / Colab, plus web and app projects

## Background

I study accounting at NCCU and take AI and programming electives. Instead of one repository per assignment, everything lives here so each course stays in one place.

Notebooks that need an API key (Gemini, Groq) read it from Colab Secrets; no keys are stored in the code, so use your own key to run them.
